# FabledEnchants

If you wish to use FabledEnchants as a dependency in your projects, FabledEnchants is available through our repository.


```xml
<repository>
    <id>magemonkey-snapshots</id>
    <url>https://repo.travja.dev/snapshots</url>
</repository>
...
<dependency>
    <groupId>studio.magemonkey</groupId>
    <artifactId>fabled-enchants</artifactId>
    <version>1.0.1-R0.5-SNAPSHOT</version>
</dependency>
```
